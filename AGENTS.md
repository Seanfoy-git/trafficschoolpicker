# Writing site content?

Any page or post with factual claims (traffic school, tickets, points, statutes,
fees) must meet the site's sourcing / honesty / state-specificity standard in
[docs/content-standards.md](docs/content-standards.md) — every fact carries ≥1
credible citation (ideally 2, primary sources preferred), and reference content
stays affiliate-clean. Run its pre-publish checklist before shipping. (The
`content` skill applies it as a procedure.)
